FONTS REQUIRED
==============

The website expects four font files in this folder. The first two are
already in place. The last two are used for the "Animeghaa Production
House" wordmark in the nav of the visual design and animation pages.

Already here
------------
- THEBOLDFONT-FREEVERSION.ttf   (headings)
- SpartanMB-SemiBold.otf        (body text)

Still needed
------------
1) More Sugar  (used for "Animeghaa" in the nav wordmark)
   Free download:  https://www.dafont.com/more-sugar.font
   Save the .ttf as one of these names inside this folder:
      MoreSugar-Regular.ttf   (preferred)
      MoreSugar.ttf
      more-sugar.ttf

2) Bimbo  (used for "Production House" in the nav wordmark)
   Free download:  https://www.dafont.com/bimbo.font
   Save the .ttf as one of these names inside this folder:
      Bimbo.ttf  (preferred)
      bimbo.ttf

Until you drop these in, the nav wordmark will fall back to Brush Script
and Marker Felt, which won't look right. Refresh the page after dropping
the files in.

The CSS also accepts .woff and .woff2 versions if you ever want to
convert them for faster loading.
